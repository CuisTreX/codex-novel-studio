# Spaces Template — Codex Novel Studio v1.0

> 版本: 1.0  
> 责任 Skill: World Bible（初稿由 Novel Architect 创建）  
> 用途: 记录所有常出现场景的空间布局与陈设，确保跨章节空间描写的一致性。

---

## 1. 使用规则

### 1.1 强制引用
- Novel Writer 在每次写作前必须读取 spaces.md。
- 涉及预设空间的内容必须严格按本文件描写。
- 不可在无记录的情况下凭空创造空间的布局细节。

### 1.2 更新流程
- 初始版本由 Novel Architect 在 Phase 0 创建。
- Phase 1 由 World Bible 完善（补充详细设定）。
- 每次 Novel Writer 完成一章后，World Bible 检查空间一致性。
- 若正文修改导致空间布局变动，需同步更新本文件。

### 1.3 空间覆盖范围
本文件应包含故事中所有反复出现或对剧情有重要影响的空间：

- 飞船/空间站/基地等主要场景的内部布局。
- 实验室/控制室/居住舱等核心功能区域。
- 城市街道/建筑物/战斗区域等外部空间。
- 交通工具内部。

## 2. 空间条目格式

### 2.1 基础格式

```markdown
## [空间名称]（统一命名，同步 Dictionary）
- **位置/方位**: 该空间在整个世界中的位置，与其他空间的关系
- **格局**: 房间划分、出入口（门/闸门/气闸）、动线
- **陈设/标志物**: 家具、设备、标志性物件、光线来源、颜色基调
- **用途**: 该空间的日常功能
- **剧情功能**: 该空间在故事中的作用、已发生的关键事件
- **空间大小**: 长/宽/高（约数），可容纳人数
- **环境特征**: 温度、湿度、重力水平、空气成分（如与地球不同）
- **技术特征**: 特殊科技装置、通信覆盖、安保级别
```

### 2.2 示例

```markdown
## 星舰"远航号"— 主控室
- **位置/方位**: 舰船前端 1 层，通过中央走廊连接舰桥和军官舱
- **格局**: 椭圆形空间，直径约 12 米。前端为全息显示屏（180°弧形），中央为舰长座椅（可升降旋转），两侧各 3 个操作台
- **陈设/标志物**: 舰长座椅右扶手上嵌有紧急制动按钮（红色）；后端入口两侧各有一组生命体征监测面板
- **用途**: 舰船指挥控制中心
- **剧情功能**: 主要决策场景发生地；第 3 章首次登场；第 12 章遭到袭击
- **空间大小**: 约 110 ㎡，可容纳 8-12 人
- **环境特征**: 标准地球重力（1g），恒温 22°C，循环空气微带臭氧味
- **技术特征**: AI 辅助指挥系统、粒子护盾控制终端、量子通信面板

## 火星殖民地— 中央穹顶市场
- **位置/方位**: 殖民地核心区，连接居住区和行政区的枢纽
- **格局**: 直径约 80 米的穹顶结构，三层环形布局。底层为食品摊位，中层为日用品和服装，顶层为电子设备和黑市
- **陈设/标志物**: 中心竖立着殖民 100 周年纪念碑（三米高的钛合金雕像）；穹顶采用仿制天空投影（每天 18 小时白昼模拟）
- **用途**: 居民购物、社交、信息交换
- **剧情功能**: 第 5 章主角在此获得关键情报；第 18 章发生枪战
- **空间大小**: 约 5000 ㎡，高峰期可容纳 2000+ 人
- **环境特征**: 火星 0.38g 重力，穹顶内加压充氧至地球标准 80%，温度 18-25°C
- **技术特征**: 穹顶透明材料为三层钛硅复合板（防微陨石）；市场内无全覆盖监控（黑市区域故意留盲区）
```

## 3. 空间一致性检查

每次写作前后进行以下检查:

- [ ] 该空间是否已在 spaces.md 中登记？
- [ ] 当前文字描写是否与 spaces.md 的预设一致？
- [ ] 角色在该空间内的移动路径是否合理（不穿越墙壁、不瞬移）？
- [ ] 空间之间的连通关系是否正确？
- [ ] 该空间内的设施/装置是否被正确使用？
- [ ] 环境特征（重力/温度/大气）是否与预设一致？

---

## 4. 空间布局变更管理

当正文需要改变某空间的布局时:

1. 评估变更对已写章节的影响。
2. 若影响已写章节 → 通知 Novel Editor 进行回归测试。
3. 更新 spaces.md 中的对应条目。
4. 在 changelog.md 中记录变更。

---

## 5. 科幻类型特殊考量

对于科幻小说，以下空间信息需要格外重视:

- **重力系统**: 人工重力/旋转重力/低重力/无重力下的空间布局差异。
- **气闸与压力舱**: 连接不同大气环境空间时的过渡区域。
- **辐射屏蔽**: 不同区域的辐射防护等级。
- **生命维持系统**: 氧气/水/食物循环系统的物理位置和接入点。
- **通信覆盖**: 哪些区域有实时通信，哪些存在信号延迟或盲区。
- **逃生路线**: 紧急情况下的撤离路线和救生舱位置。
