# 06 Translation Editor — Codex Novel Studio v1.0

> **技能名称**: Translation Editor（出版级创译编辑）  
> **版本**: 1.0  
> **职责等级**: ⭐⭐⭐⭐（强烈推荐）  
> **适用范围**: Phase 5（可选但强烈推荐）  
> **核心原则**: 不是翻译——是创译。让英文版读起来像北美本土作者写的，完全不像翻译。

---

## 1. 职责定义

Translation Editor 负责将完成的中文版小说创译为可出版的英文版本。  
与其说它是翻译，不如说它是"用英文重写这个故事"。

### 1.1 核心职责
- 文化转换：将中文特有文化元素替换为北美读者可理解和欣赏的等效元素。
- 对白重写：使对话完全符合英语母语者的表达习惯和节奏。
- 节奏调整：根据英语语言的节奏特性调整句式长度和段落结构。
- 幽默调整：将中文语境下的幽默转为北美读者能够理解和欣赏的幽默。
- 俚语与口语调整：使用适合角色身份的当代英语俚语和口语表达。
- 叙事节奏重校准：英文的叙事节奏不同于中文，需要重新校准。
- 最终润色至出版级质量。

### 1.2 不承担的职责
- 逐字逐句翻译（禁止——这是创译，不是翻译）。
- 保留中文特有的修辞和表达（文化负载项需要转换，不是保留）。
- 修改 Story Bible / Character Bible / World Bible 的内容（设定不变，仅语言）。
- 改变故事情节、角色设定、世界观规则（仅语言本土化）。

## 2. 创译 vs 翻译

### 2.1 核心区别
| 维度 | 翻译 | 创译 (Transcreation) |
|------|------|---------------------|
| 目标 | 准确传达原文意思 | 让读者感受到原文读者同样的体验 |
| 语言 | 尽量忠实原文 | 为目标读者重新创作 |
| 文化 | 保留文化元素，加注解释 | 替换为等效文化元素 |
| 节奏 | 跟随原文节奏 | 根据目标语言重新调整 |
| 对白 | 直译对话 | 重写对话使其自然 |
| 阅读体验 | 读起来像翻译作品 | 读起来像原创作家写的 |

### 2.2 创译标准
**如何判断创译成功？**
- 北美读者读完一章，不会在任何时候想到"这可能是翻译作品"。
- 如果告诉读者这是美国作者写的，读者不会有合理怀疑。
- 读者会忘记语言的存在，完全沉浸在故事中。

## 3. 创译工作流程

### 3.1 第一阶段: 分析与规划
**输入**: 编辑后的最终中文版全文。  
**输出**: 创译策略文档。

**分析内容**:
1. **文化负载项清单**: 列出所有需要文化转换的元素。
   - 中国特色习俗/节日/典故。
   - 中国特有的社会现象/制度。
   - 基于中文语境的幽默/双关。
   - 中国文学传统中的修辞手法。
   - 食物/服饰/建筑等文化元素的处理方式。

2. **语言特性差异分析**:
   - 中文偏好短句、四字格、对仗 → 英文需要连接词、从句、逻辑词。
   - 中文主语省略常见 → 英文需要明确主语。
   - 中文时间顺序靠语序体现 → 英文靠时态和连接词。
   - 中文描写更写意、留白 → 英文需要适度的具体描写。

3. **角色语言特征转换计划**:
   - 每个角色的语言特征（来自 Character Bible）需要在英文中重建。
   - 例如: 一个说话文绉绉的中文角色，英文版本要用古语词还是正式句式来表达？需要决策。

4. **节奏映射计划**:
   - 中文和英文的信息密度不同（同样篇幅的中文承载信息多于英文）。
   - 需要规划章节篇幅调整（英文版可能需要更长篇幅才能达到同等的叙事密度）。

### 3.2 第二阶段: 初稿创译
**方法**: 逐章创译，每章独立完成。

**每章创译流程**:
1. 阅读中文原章，理解叙事目标、角色状态、情感曲线。
2. 关闭中文原文，仅凭理解写英文版本。
3. 写作语言为英文；过程中优先保持英文的流畅性而非对原文的忠实度。
4. 写完后对比中文原文，确保:
   - 所有关键信息已包含。
   - 角色情感弧线一致。
   - 节奏曲线一致。
   - 无信息丢失或误写。

**禁止行为**:
- ❌ 逐句翻译。
- ❌ 保持中文句式结构。
- ❌ 在英文中使用中文词汇（除非在 Dictionary 中有明确定义且符合叙事目的）。
- ❌ 用括号加注原文。
- ❌ 使用 "as Chinese saying goes" 等说明性文字。

### 3.3 第三阶段: 文化转换

**转换策略**:

| 文化元素类型 | 推荐策略 | 示例 |
|-------------|----------|------|
| 特有实物（食物/物品） | 保留专有名词，融入描述解释 | "饺子"→ "jiaozi, pockets of dough filled with seasoned meat" |
| 特有概念（关系/观念） | 找近似替代 | "面子"→ 根据语境转换为 pride / reputation / dignity |
| 成语/谚语 | 找功能等效的英语表达 | "对牛弹琴"→ "like speaking to a wall" |
| 历史/文学引用 | 替换为西方读者熟悉等效引用，或删除 | "诸葛亮"→ 若必须保留加身份描述 |
| 社会制度 | 直接解释或替换为近似概念 | "居委会"→ "community committee" 或直接解释功能 |
| 幽默/双关 | 在英文中重新创作等效幽默 | 不依赖双关字，而是用情境幽默替代 |
| 诗歌/韵文 | 重新创作，保证节奏和韵律 | 不直译诗意，而是用英文诗歌手法重写 |

### 3.4 第四阶段: 对白重写

**原则**:
- 中文对话在译为英文后，90% 的情况下需要重写句式。
- 中文对话中常用的语气词（啊、嘛、吧、呢）转换成英文的语调、省略和助动词。
- 角色身份和关系通过英文中的称呼、语气正式度、用词选择体现。

**转换对照示例**:
```
中文: "你为什么要这么做？我以为我们是朋友。"
直译: "Why did you do this? I thought we were friends."
创译: "Why?" Her voice cracked. "I thought we were friends."

中文: "这件事没那么简单，你得听我解释。"
直译: "This matter is not that simple, you need to listen to my explanation."
创译: "It's not what it looks like. Let me explain."
```

### 3.5 第五阶段: 节奏调整

**英文节奏特征**:
- 句子长度: 平均 15-20 词（中文平均每句 20-30 字）。
- 段落: 更短。叙事段落 3-5 句，动作场景 1-3 句。
- 留白: 英文需要更多 transition word 来连接逻辑。
- 对话标签: 更丰富。said/asked/whispered/shouted 等 + 动作描写。

**调整策略**:
- 中文一段 → 英文可能拆成 2-3 段。
- 中文长复合句（尤其描写性的）→ 断为 2-3 个英文句子。
- 英文中需要补充连接词和因果关系词（because, so, although, while 等）。
- 中文简洁有力的短句 → 英文可能需要补充主语和语境信息，但同样要保持冲击力。

### 3.6 第六阶段: 母语者润色

**最终检查清单**:
- [ ] 没有任何"中式英语"痕迹。
- [ ] 句式自然，是母语者会写出的句子。
- [ ] 文化引用不需要加注说明北美读者也能理解。
- [ ] 对话节奏自然，不僵硬。
- [ ] 角色语言差异在英文中体现得和中文一样明显。
- [ ] 阅读节奏流畅，没有"卡顿感"。
- [ ] 长段落是否合理分段适应英文阅读习惯。
- [ ] 是否过度使用某种句式模式（避免单一结构）。
- [ ] 是否使用了过时或不当的俚语。
- [ ] 是否有未意识到的中文母语者特有的语法错误（冠词缺失、时态混淆、介词误用、主谓一致等）。

## 4. 常见错误对照表

| 中文思维错误 | 示例 | 修正 |
|-------------|------|------|
| 缺少冠词 (a/an/the) | "She is writer." | "She is a writer." |
| 可数/不可数混淆 | "He gave me an advice." | "He gave me some advice." |
| 介词误用 | "discuss about" | "discuss"（无 about） |
| 时态不连贯 | 在同一段中无理由切换时态 | 保持叙事时态一致 |
| 主谓一致错误 | "The data shows..." | "The data show..."（学术语境） |
| 冗余修饰 | "advance planning" | "planning" |
| 误用假朋友 | "I will reconsider" 当 "我会考虑" | "I will consider" |
| 过度正式 | "commence" 而非 "start" | 看语境，对话中用 start |

## 5. 质量签收标准

### 5.1 最终签收清单
- [ ] 所有章节创译完成。
- [ ] 文化转换一致，无遗留中文特有元素。
- [ ] 对白在所有章节中风格统一。
- [ ] 角色语言特征在英文版本中保持差异化。
- [ ] 阅读节奏流畅。
- [ ] 无 P0/P1 质量问题。
- [ ] 经至少一次全篇通读，没有"翻译感"。
- [ ] 术语使用与 Dictionary 一致（英文版术语）。
- [ ] 语法和拼写完全正确。

### 5.2 签收测试
**"盲测"**: 让一位英语母语者阅读前 3 章，不告知是翻译作品。  
- 如果对方主动问"这作者是美国人吗" → 通过。
- 如果对方主动问"这是翻译的吗" → 未通过，需要重新修改。

**"读感测试"**: 
- 找出 5 个你认为最像翻译的句子。
- 如果 5 个中有 3 个以上被母语者也标记为"不自然"→ 未通过。
